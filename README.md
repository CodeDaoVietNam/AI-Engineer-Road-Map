# AI Engineer Roadmap

A practical learning repository for becoming an AI Engineer who can design, build, evaluate, deploy, and explain production-oriented RAG and AI Agent systems.

## Learning sequence

1. Start with the eight-week [System Design roadmap](roadmap/AI_ENGINEER_SYSTEM_DESIGN_ROADMAP.md). Build a working Enterprise Document RAG Assistant from requirements through deployment.
2. Continue with the [Advanced AI and Cloud roadmap](roadmap/ADVANCED_AI_ENGINEER_AND_CLOUD_ROADMAP.md). Extend the same capstone with model foundations, agents, MCP, multimodal AI, serving, Azure, and LLMOps.

Study one main topic per session. During the System Design path, use advanced AI or Azure material only when it directly supports the current milestone.

## Repository guide

- `learning-paths/00-setup/` — environment and prerequisite checks.
- `learning-paths/01-system-design-rag/` — the primary eight-week path.
- `learning-paths/02-advanced-ai-cloud/` — the follow-on advanced path.
- `capstone/enterprise-document-rag-assistant/` — one project that grows with the curriculum.
- `docs/` — architecture diagrams, decision records, system-design notes, and portfolio material.
- `resources/` — curated study guides.
- `templates/` — reusable files for sessions, modules, experiments, and decisions.

## Module contract

Copy [the weekly module template](templates/weekly-module.md) when starting a new week or topic. A module is complete only when it contains:

1. A knowledge note in your own words.
2. A practical artifact: code, diagram, dataset sample, API design, or infrastructure configuration.
3. A measurement: quality, latency, throughput, error rate, or cost.
4. A decision record that explains alternatives, trade-offs, and when to revisit the decision.

## Start a study session

Copy [the learning-session template](templates/learning-session.md), select one topic, and record what you understand before and after the session. Use [the System Design Primer guide](resources/system-design-primer.md) as a supporting resource, not a checklist to read linearly.

## Capstone milestones

1. Requirements, SLOs, APIs, and data model.
2. Authenticated upload and asynchronous document ingestion.
3. Access-controlled retrieval with citations and evaluation.
4. Reliability, observability, deployment, and portfolio documentation.
5. Advanced extensions: agents, MCP, multimodal processing, Azure, and LLMOps.
