# Cloud and Azure Study Guide

Learn cloud concepts in a cloud-neutral way first, then map them to Azure when the capstone needs them. Prioritize identity, secrets, storage, databases, queues, networking, compute, observability, security, Infrastructure as Code, CI/CD, reliability, and FinOps.

For each Azure service, document the problem it solves, its alternative, its cost or operational trade-off, and how it fits the capstone architecture.
