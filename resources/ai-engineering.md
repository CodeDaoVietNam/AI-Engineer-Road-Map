# AI Engineering Study Guide

After the System Design path, focus on model foundations, structured output, context engineering, tool calling, agents, MCP, evaluation, multimodal retrieval, fine-tuning, and inference serving. Each topic should improve a measurable part of the capstone rather than become an isolated tutorial.

Useful measurements include retrieval recall, citation correctness, task success, latency, token usage, throughput, failure rate, and cost.
